# ADR-2026-04: BFF에서 직접 DB 접속 금지

## 상태

수락

## 맥락

`DL-BFF`가 `orders-db`에 직접 접속하면 연결 폭주 시 장애 반경이 커짐. 인시던트 **INC-2026-0412**에서 증명(가상).

## 결정

- BFF → **내부 API 게이트웨이** → DB 경로로 제한.
- 커넥션 풀은 게이트웨이 단에서만 관리.

## 결과

- 긍정: 장애 반경 축소, 권한 분리 명확.
- 부정: 홉 1 증가, 지연 소폭 증가 가능 — SLO 여유 내(가정).
